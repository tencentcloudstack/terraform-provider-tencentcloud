## Why

The DTS `tencentcloud_dts_sync_config` resource currently only supports table-level `table_name`, `new_table_name`, and `filter_condition` fields inside the `objects.databases.tables[]` block. The underlying DTS cloud API `Table` object (used by both `ConfigureSyncJob` and `DescribeSyncJobs`) exposes additional capabilities — column-level partial synchronization, temporary-table synchronization for pt-osc/gh-ost, and a table edit mode — that are not yet surfaced in the Terraform schema. Users who need to synchronize only a subset of columns, rename columns, or sync temporary tables generated by online DDL tools cannot express these configurations through Terraform today.

## What Changes

- Add an optional `column_mode` string field to the `objects.databases.tables[]` block, mapping to the cloud API `Table.ColumnMode` (values `All` / `Partial`).
- Add an optional `columns` list field to the `objects.databases.tables[]` block, mapping to the cloud API `Table.Columns`, where each entry exposes:
  - `column_name` → `Column.ColumnName`
  - `new_column_name` → `Column.NewColumnName`
- Add an optional `tmp_tables` set-of-strings field to the `objects.databases.tables[]` block, mapping to the cloud API `Table.TmpTables`.
- Add an optional `table_edit_mode` string field to the `objects.databases.tables[]` block, mapping to the cloud API `Table.TableEditMode` (values `rename` / `pt`).
- Wire these fields through the `ConfigureSyncJob` write path (update) and the `DescribeSyncJobs` read path so that state is consistent.

All new fields are optional and backwards compatible; existing configurations and state are unaffected.

## Capabilities

### New Capabilities
- `dts-sync-config-table-column-sync`: Enables the `tencentcloud_dts_sync_config` resource to configure column-level partial synchronization, column renaming, temporary-table synchronization (for pt-osc/gh-ost), and table edit mode within the `objects.databases.tables[]` block.

## Impact

- **Resource schema**: `tencentcloud/services/dts/resource_tc_dts_sync_config.go` — extend the `objects.databases.tables[]` block schema with `column_mode`, `columns`, `tmp_tables`, and `table_edit_mode`.
- **Read path**: `resourceTencentCloudDtsSyncConfigRead` — populate the new fields from the `DescribeSyncJobs` response (`Table.ColumnMode`, `Table.Columns`, `Table.TmpTables`, `Table.TableEditMode`).
- **Write path**: `resourceTencentCloudDtsSyncConfigUpdate` — send the new fields in the `ConfigureSyncJob` request.
- **Documentation**: `tencentcloud/services/dts/resource_tc_dts_sync_config.md` and generated `website/docs/r/dts_sync_config.html.markdown`.
- **Tests**: `tencentcloud/services/dts/resource_tc_dts_sync_config_test.go` — add/update test cases covering the new fields.
- **Cloud API dependency**: `github.com/tencentcloud/tencentcloud-sdk-go/tencentcloud/dts/v20211206` — `Table` and `Column` structs already expose the required fields; no SDK upgrade needed.
