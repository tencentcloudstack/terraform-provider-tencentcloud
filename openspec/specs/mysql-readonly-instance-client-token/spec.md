## Requirements
### Requirement: Readonly instance create MUST attach a client token

The `tencentcloud_mysql_readonly_instance` resource Create flow SHALL generate a client token using `helper.BuildToken()` and attach it to the `ClientToken` field of both the `CreateDBInstance` (prepaid/包年包月) and `CreateDBInstanceHour` (postpaid/按量计费) requests before calling the cloud API.

#### Scenario: Client token is set on prepaid create request
- **WHEN** a readonly instance is created with prepaid billing (payType == MysqlPayByMonth)
- **THEN** the `CreateDBInstanceRequest.ClientToken` field MUST be a non-empty string generated by `helper.BuildToken()`

#### Scenario: Client token is set on postpaid create request
- **WHEN** a readonly instance is created with postpaid billing (payType == MysqlPayByUse)
- **THEN** the `CreateDBInstanceHourRequest.ClientToken` field MUST be a non-empty string generated by `helper.BuildToken()`

### Requirement: Readonly instance create MUST retry on empty instance ids

The `tencentcloud_mysql_readonly_instance` resource Create flow SHALL wrap the `CreateDBInstance` / `CreateDBInstanceHour` API call in a `resource.Retry`. When the response returns an empty `InstanceIds` list AND a client token was provided, the system SHALL return a `RetryableError` so the call is retried idempotently using the same client token.

#### Scenario: Retry when API returns empty instance ids
- **WHEN** the create API responds with a non-nil response but `len(response.Response.InstanceIds) < 1`
- **AND** a client token was set on the request
- **THEN** the system MUST return a `resource.RetryableError` and retry the same API call within `2*tccommon.WriteRetryTimeout`

#### Scenario: Succeed when API returns instance id
- **WHEN** the create API responds with exactly one instance id in `response.Response.InstanceIds`
- **THEN** the system MUST set `d.Id()` to that instance id and stop retrying

#### Scenario: Surface error on API failure
- **WHEN** the create API returns an error
- **THEN** the system MUST wrap it with `tccommon.RetryError` so retryable SDK errors are retried and non-retryable errors are surfaced

### Requirement: Readonly instance create client token must be a generated random token

The client token used by the `tencentcloud_mysql_readonly_instance` create flow SHALL be generated by `helper.BuildToken()` (a 16-byte random base64 token), consistent with the master instance (`tencentcloud_mysql_instance`) create logic. It SHALL NOT be a user-supplied schema field.

#### Scenario: Token generation mechanism
- **WHEN** the readonly instance create flow builds the create request
- **THEN** the client token MUST be produced by `helper.BuildToken()` and MUST NOT be exposed as a terraform schema argument
