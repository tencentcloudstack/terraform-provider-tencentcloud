# tencentcloud_ioa_delivery_server

Provides a resource to create or update an IOA (iOA) log delivery server.

The create and update paths reuse the `ModifyDeliveryServer` API: on create the
server id inside `data` is ignored and the API-generated id is returned and
tracked as the resource `id`; on update the create-time id is sent as `Data.ID`.

## Example Usage

```hcl
resource "tencentcloud_ioa_delivery_server" "example" {
  data {
    name                   = "tf-example-syslog"
    type                   = 4
    description            = "syslog delivery server managed by terraform"
    target_syslog_address  = "10.0.0.1"
    target_syslog_protocol = "udp"
    target_syslog_port     = 514
    syslog_facility        = "local0"
  }
}
```

### Kafka delivery server:

```hcl
resource "tencentcloud_ioa_delivery_server" "kafka" {
  data {
    name                 = "tf-example-kafka"
    type                 = 2
    description          = "kafka delivery server managed by terraform"
    target_kafka_address = "10.0.0.2:9092"
    target_kafka_topic   = "ioa-log"
    kafka_version        = "2.8.0"
    kafka_sasl_user_name = "sasl-user"
    kafka_sasl_password  = "sasl-pass"
    kafka_ssl_enable     = true
    ssl_skip_verify      = false
  }
}
```

### HTTP delivery server:

```hcl
resource "tencentcloud_ioa_delivery_server" "http" {
  data {
    name                = "tf-example-http"
    type                = 3
    description         = "http delivery server managed by terraform"
    target_http_url     = "http://10.0.0.3/collect"
    target_http_timeout = 3000
  }
}
```

### ## Import

IOA delivery server can be imported using the server id, e.g.

```hcl
terraform import tencentcloud_ioa_delivery_server.example 12345
```

## Argument Reference

The following arguments are supported:

* `data` - (Optional, Object) Delivery server definition. All fields are optional on the API side; fields relevant to the selected `type` should be provided.

The `data` object supports the following:

* `connector_group_id` - (Optional, String) Connector group id.
* `connector_group_name` - (Optional, String) Connector group name.
* `description` - (Optional, String) Delivery server description.
* `id` - (Optional, Int) Server id. Ignored on create; on update Terraform always sends the server id tracked in the top-level `id`.
* `kafka_sasl_password` - (Optional, String) Kafka SASL password.
* `kafka_sasl_user_name` - (Optional, String) Kafka SASL user name.
* `kafka_ssl_enable` - (Optional, Bool) Whether SSL is enabled for Kafka.
* `kafka_version` - (Optional, String) Kafka version.
* `name` - (Optional, String) Delivery server name.
* `ssl_skip_verify` - (Optional, Bool) Whether to skip certificate verification.
* `syslog_facility` - (Optional, String) Syslog facility.
* `target_http_timeout` - (Optional, Int) HTTP server timeout in milliseconds (32-bit only).
* `target_http_url` - (Optional, String) HTTP server address.
* `target_kafka_address` - (Optional, String) Kafka server address.
* `target_kafka_topic` - (Optional, String) Kafka topic.
* `target_syslog_address` - (Optional, String) Syslog server address.
* `target_syslog_port` - (Optional, Int) Syslog protocol port (32-bit only).
* `target_syslog_protocol` - (Optional, String) Syslog protocol type.
* `type` - (Optional, Int) Delivery server address type. Valid values: 4 (syslog), 2 (kafka), 3 (http, 32-bit only).

## Attributes Reference

In addition to all arguments above, the following attributes are exported:

* `id` - ID of the delivery server, generated by the cloud side on create.

* Update:
  - [DescribeDeliveryServer](https://www.tencentcloud.com/search/?wd=DescribeDeliveryServer&type=document&lang=en)
  - [ModifyDeliveryServer](https://www.tencentcloud.com/search/?wd=ModifyDeliveryServer&type=document&lang=en)
* Delete: [DeleteDeliveryServer](https://www.tencentcloud.com/search/?wd=DeleteDeliveryServer&type=document&lang=en)
