# tencentcloud_teo_custom_group

Provides a resource to create a TEO (EdgeOne) custom group. A custom group is a reusable collection of items (TLS fingerprints, UA values or Referer values) that can be referenced by security rules. The group type is immutable after creation; the group name and the item list can be updated in place.

~> **NOTE:** The cloud API keeps the previous value when `group_name` or `group_items` is omitted on update. Since both attributes are required, the configured list fully replaces the cloud-side items (`GroupItemOperation=Replace`). Emptying the item list is rejected by the provider because the behavior of `Replace` with an empty list is not confirmed by the TEO API; remove unneeded items individually or recreate the group instead.

~> **NOTE:** Deleting the resource only removes the custom group itself. Whether a group that is still referenced (`ref_count > 0`) can be deleted is decided by the cloud API.

## Example Usage

```hcl
resource "tencentcloud_teo_custom_group" "example" {
  zone_id    = "zone-27h0vbm5w1e"
  group_name = "tf-example-group"
  group_type = "TLSFingerprint"
  group_items = [
    {
      content   = "cd08b7ecb0e6f5a72c6f5a8ea17e2e5a"
      item_type = "JA3"
    },
    {
      content   = "t13d1714h2_8daaf6b1a14185f4"
      item_type = "JA4"
    },
  ]
}
```

## Argument Reference

The following arguments are supported:

* `group_items` - (Required, List) Item list of the custom group. On update the configured list fully replaces the cloud-side items (GroupItemOperation=Replace).
* `group_name` - (Required, String) Name of the custom group.
* `group_type` - (Required, String) Type of the custom group, immutable after creation. Different group types support different item types. Valid values: `TLSFingerprint` (TLS fingerprint group, supports JA3/JA4 items), `UA` (UA group, supports UA items), `Referer` (Referer group, supports Referer items).
* `zone_id` - (Required, String) Site ID. The zone the custom group belongs to. Not returned by the describe API; after create it keeps the configured value.

The `group_items` object supports the following:

* `content` - (Required, String) Content of the item.
* `item_type` - (Required, String) Type of the item. Valid values: `JA3` (JA3 fingerprint, only when the group type is TLSFingerprint), `JA4` (JA4 fingerprint, only when the group type is TLSFingerprint), `UA` (UA value, only when the group type is UA), `Referer` (Referer value, only when the group type is Referer).

## Attributes Reference

In addition to all arguments above, the following attributes are exported:

* `group_id` - Unique ID of the custom group, generated by the cloud side on create.
* `group_item_total_count` - Total number of items in the custom group.
* `id` - ID of the resource, in `<zone_id>#<group_id>` format.
* `ref_count` - Number of times the custom group is referenced.

## API Reference

This resource interacts with the following TencentCloud APIs:

* Create:
  - [CreateCustomGroup](https://www.tencentcloud.com/search/?wd=CreateCustomGroup&type=document&lang=en)
  - [DescribeCustomGroup](https://www.tencentcloud.com/search/?wd=DescribeCustomGroup&type=document&lang=en)
* Read: [DescribeCustomGroup](https://www.tencentcloud.com/search/?wd=DescribeCustomGroup&type=document&lang=en)
* Update:
  - [DescribeCustomGroup](https://www.tencentcloud.com/search/?wd=DescribeCustomGroup&type=document&lang=en)
  - [ModifyCustomGroup](https://www.tencentcloud.com/search/?wd=ModifyCustomGroup&type=document&lang=en)
* Delete: [DeleteCustomGroup](https://www.tencentcloud.com/search/?wd=DeleteCustomGroup&type=document&lang=en)

## Import

TEO custom group can be imported using the composite id in `<zone_id>#<group_id>` format, e.g.

````
terraform import tencentcloud_teo_custom_group.example zone-27h0vbm5w1e#cg-2qbzqqti0e9z
````
